# Primitive DB

Учебный проект консольной базы данных на Python.
Реализованы создание и удаление таблиц, просмотр списка и сохранение их структуры
в JSON между запусками приложения.
Для управления проектом используется uv, для проверки кода — Ruff.

## Требования

- Python 3.12 или новее. При необходимости uv загрузит Python автоматически.
- uv версии 0.5 или новее.
- Git.

Команды приведены для Windows CMD. Клонирование выполняйте из папки для проектов,
остальные команды — из корня проекта.

## Установка

```bat
git clone https://github.com/ozimandiax/project2_Borodin_M26-555.git
cd project2_Borodin_M26-555
uv sync
```

## Запуск

```bat
uv run database
```

Также приложение можно запустить как модуль:

```bat
uv run python -m primitive_db.main
```

При запуске приложение показывает справку и запрашивает команду.

## Управление таблицами

| Команда | Назначение |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Выйти из приложения |

Поддерживаются типы столбцов `int`, `str`, `bool`. Системный столбец `ID:int`
автоматически добавляется первым. Если он указан явно, второго ID не создаётся.
Повторяющиеся имена столбцов, неверные типы и неверный тип ID отклоняются.

Пример команд внутри приложения:

```text
create_table users name:str age:int is_active:bool
list_tables
drop_table users
exit
```

При создании проверяется, что имя таблицы ещё не занято; при удалении — что таблица
существует. Неизвестные команды и неверные аргументы не завершают приложение.
Имена с пробелами можно заключать в кавычки, например:

```text
create_table "project users" name:str
drop_table "project users"
```

## Хранение метаданных

Метаданные хранятся в `db_meta.json` в текущей рабочей папке. Если файла ещё нет,
используется пустой словарь. После успешного создания или удаления таблицы изменения
сохраняются. При следующем запуске из той же папки таблицы остаются доступны.

Пример структуры файла:

```json
{
    "users": ["ID:int", "name:str", "age:int", "is_active:bool"]
}
```

Повреждённый JSON вызывает сообщение об ошибке и не заменяется пустой базой.
Файл с локальными метаданными исключён из Git.

## Проверка кода

```bat
uv run ruff check .
```

## Сборка и проверка пакета

```bat
uv build
uvx twine check dist\primitive_db-0.3.0-py3-none-any.whl dist\primitive_db-0.3.0.tar.gz
```

## Установка собранного пакета

Если виртуальное окружение активировано, сначала выполните `deactivate`,
чтобы проверить команду из отдельно установленного пакета.

```bat
uv tool install --force --reinstall dist\primitive_db-0.3.0-py3-none-any.whl
database
```

Если uv сообщает, что каталог инструментов отсутствует в `PATH`, выполните
`uv tool update-shell` и перезапустите терминал.
