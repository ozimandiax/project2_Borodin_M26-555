# Primitive DB

Учебный проект консольной базы данных на Python.
На этапе подготовки реализованы запуск приложения, справка и выход.
Для управления проектом используется uv, для проверки кода — Ruff.

## Требования

- Python 3.12 или новее. При необходимости uv загрузит Python автоматически.
- uv версии 0.5 или новее.
- Git.

Команды приведены для Windows CMD. Клонирование выполняйте из папки для проектов,
остальные команды — из корня проекта.

## Установка

```bat
git clone https://github.com/ozimandiax/project2_Borodin_M26-555.git
cd project2_Borodin_M26-555
uv sync
```

## Запуск

```bat
uv run project
```

Также приложение можно запустить как модуль:

```bat
uv run python -m primitive_db.main
```

При запуске приложение показывает справку и запрашивает команду.

- `help` — повторно показать справку.
- `exit` — выйти из приложения.

При неизвестной команде выводится сообщение, после чего ввод запрашивается снова.

## Проверка кода

```bat
uv run ruff check .
```

## Сборка и проверка пакета

```bat
uv build
uvx twine check dist\primitive_db-0.2.0-py3-none-any.whl dist\primitive_db-0.2.0.tar.gz
```

## Установка собранного пакета

Если виртуальное окружение активировано, сначала выполните `deactivate`,
чтобы проверить команду из отдельно установленного пакета.

```bat
uv tool install --force --reinstall dist\primitive_db-0.2.0-py3-none-any.whl
project
```

Если uv сообщает, что каталог инструментов отсутствует в `PATH`, выполните
`uv tool update-shell` и перезапустите терминал.
